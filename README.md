# Ely's Chef 🍳

Aplicación web de recetas inteligentes con IA. El usuario introduce 
los ingredientes que tiene en casa y la app sugiere recetas personalizadas 
usando inteligencia artificial.

Desarrollada como Trabajo de Fin de Grado del Ciclo Superior en DAM.

## Demo
🔗 [elys-chef.vercel.app](https://elys-chef.vercel.app)

![Captura de Ely's Chef](./screenshots/demo2.png)

## Tecnologías
- React + TypeScript + Vite
- Tailwind CSS + shadcn-ui
- API de IA para generación de recetas

## Instalación
```sh
git clone https://github.com/SrPineappleDev/ElysChef.git
cd smart-recipe-ai
npm install
npm run dev
```
