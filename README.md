# Ely's Chef

## Información del proyecto

Aplicación web de recetas inteligentes con inteligencia artificial, construida con React, TypeScript y Vite.

## ¿Cómo editar el código?

**Usando tu IDE preferido**

Clona el repositorio y trabaja localmente. Solo necesitas tener Node.js y npm instalados.

```sh
# Paso 1: Clona el repositorio.
git clone <URL_DEL_REPOSITORIO>

# Paso 2: Navega al directorio del proyecto.
cd smart-recipe-ai

# Paso 3: Instala las dependencias.
npm install

# Paso 4: Inicia el servidor de desarrollo.
npm run dev
```

**Editar directamente en GitHub**

- Navega al archivo deseado.
- Haz clic en el botón "Edit" (ícono de lápiz) en la esquina superior derecha.
- Realiza tus cambios y haz commit.

**Usar GitHub Codespaces**

- Ve a la página principal del repositorio.
- Haz clic en el botón "Code" (botón verde).
- Selecciona la pestaña "Codespaces".
- Haz clic en "New codespace" para lanzar un nuevo entorno.
- Edita y haz commit desde el Codespace.

## Tecnologías utilizadas

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## ¿Cómo desplegar el proyecto?

Puedes desplegar la aplicación en cualquier plataforma que soporte sitios estáticos (Vercel, Netlify, GitHub Pages, etc.).

```sh
# Genera el build de producción.
npm run build
```

El resultado se genera en la carpeta `dist/`, lista para ser desplegada.
